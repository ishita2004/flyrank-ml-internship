## 2. Identity Kit & Style Guide

- **Heading Font:** `Inter` (Weight: 700 Bold, Letter-spacing: `-0.02em`)

```text
┌───────────────────┬───────────┬────────────────────────────────────────┐
```

### Standing System Instruction Style Note
```markdown
# Portfolio Visual Identity Rule
Keep the interface quiet so the real work and data charts are the loudest elements on the page.
Typography: Inter (Heading 700) and Geist (Body 400).
Palette: #0f172a text on #f8fafc background; #2563eb accent for links; #16a34a for positive metric callouts.
Never add decorative AI hero graphics, glowing gradients, or animated particles.
```
